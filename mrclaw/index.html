常见问题

关于 MRClaw 的常见问题解答。没找到答案？右上角咨询客服。

MRClaw 是什么？

一个装在安卓手机上的 AI 助手。打开就是聊天界面，可以用积分或自己的 API Key 对话；开启无障碍权限后，还能让 AI 替你操作手机。

怎么安装 MRClaw？

点页面上的「下载 APK」，安装时允许「安装未知应用」即可。安卓 8.0 及以上。若在微信里打开，请点右上角 ··· 选择「在浏览器打开」再下载。

支持哪些 AI 模型？

内置智谱、DeepSeek、通义千问、豆包、Kimi、文心一言、讯飞星火、腾讯混元，也可以填任意 OpenAI 兼容接口。

不填 API Key 能用吗？

可以。注册送 30 万积分，直接用积分聊天（1 token = 1 积分）。积分用完可以充值，也可以填自己的 Key。

运行 MRClaw 要花多少钱？

软件本身免费。用积分模式按量消耗积分（可充值）；用自己的 Key 则只付给模型厂商，我们不参与计费。

我的数据安全吗？

用自己 Key 时对话直连模型厂商；积分模式走的是我们的服务端中转，服务端密钥绝不下发到手机。账号与配置存在云端，仅用于同步。
