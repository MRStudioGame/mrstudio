🛠 修复日志

从建立网站以来，我们记录并修复的所有问题

  • 1官网下载太慢（GitHub 直连仅 0.02MB/s）——已启用镜像加速，实测提升到 1.2~8.2MB/s，并保留官方下载作为备用
  • 2Windows 版安装包被 SmartScreen 拦截提示——已改用免安装绿色版 zip 作为主下载，避免弹窗困扰
  • 3官网在线人数统计不真实——已改为真实访问统计（不蒜子），数据可靠
  • 4官网背景音乐自动播放被浏览器拦截——已改为手动点击播放，不打扰浏览
  • 5官网"帮助与教程"弹窗打扰浏览——已改为页面内锚点滚动定位，不再弹窗
  • 6学习网站"在线运行代码"依赖服务器执行，免费主机不支持——已改为浏览器端运行（Pyodide），无需服务器执行
  • 7学习网站选择题提交答案无反应——已修复脚本损坏问题，提交、判分、反馈全部正常
  • 8手机控制台连不上 PythonAnywhere API（网络限制）——已由学习网站自身代理转发，状态查询、重启、日志、维护开关全部可用
  • 9官网广播文字滚到最左边直接消失——已修复为平滑循环滚动，并根据使用反馈回归原流动方式
  • 10广播速度只能靠感觉调——已加控制台实时速度演示，所见即所得，还支持定时开关
  • 11学习网站无法远程维护——已加入维护开关与自定义公告，控制台可一键开启/关闭，支持定时
  • 12官网无法远程广播通知——已加入官网流动广播，支持自定义内容、速度、直接开关与定时广播
  • 13学习网站选择题提交答案无反应——已修复脚本损坏问题，提交、判分、反馈全部正常
  • 14学习网站无法管理注册用户——已加入用户管理，支持查看用户统计（总注册/在线）、账号信息，以及封号、注销、发消息等管理操作
  • 15控制台用户管理页一直加载/加载失败——已修复跨域（CORS）问题，管理接口统一允许跨域调用并支持预检请求，用户管理、封号、注销、发消息全部恢复正常
  • 16控制台用户管理按钮点击无响应——已改用自绘弹窗（WebView 不支持原生输入/确认框），封号、注销、发消息等操作全部可用
  • 17用户管理看不到登录密码——已支持查看明文密码，新注册用户的登录密码可直接查看（旧账号因加密不可还原，显示无明文记录）
  • 18注销的账号仍保留在用户列表中——已支持最终注销，管理员可彻底删除账号及其全部数据（进度/积分/签到/消息），删除后查不到任何信息
  • 19学习网站时间显示错误（慢8小时）——已统一为东八区时间，并修正全部历史数据
  • 20学习网站无对战玩法——已加入 PK 对战模式：支持机器人 PK 与在线匹配 PK，每局 5 道随机题（4 选择 + 1 压轴），结算页展示战况与对局 ID，支持举报对手
  • 21控制台无对局管理——已加入对局管理页：待处理举报提醒、按对局 ID 搜索查看逐题详情（双方耗时/题目/账号 ID），用户管理支持按账号 ID/名称搜索并显示 PK 胜负战绩
  • 22PK 结算页对局 ID 旁缺少举报按钮——已在对局 ID 旁直接加入举报按钮，点击弹出输入框填写对方违规行为并提交，管理员可在控制台处理
  • 23控制台对局信息展示不全——已完善对局详情：显示每道题的选项、双方各自选择与耗时、双方账号昵称/ID，举报列表显示举报人与被举报人用户名
  • 24已处理的举报仍显示在控制台——已隐藏已处理举报，对局管理只显示待处理举报，处理完自动消失
  • 25只有爬虫学习网站，没有英语学习网站——已新增英语闯关学习网站（/english/）：12 关英语课程、注册登录、签到积分、PK 对战，独立数据库与题库；官网已加入口
  • 26控制台只能管理爬虫网站——已支持英语网站管理：状态检测、维护开关、用户管理、对局管理（站点切换），爬虫站与英语站功能一致；两个网站的网页版也内置了管理面板（用户管理+对局管理）
  • 27控制台每次更新都要重新下载 APK——已实现自动更新：控制台页面托管到线上，老版 App 打开时自动加载最新版（离线自动回退本地），以后更新功能无需重新安装
  • 28官网爬虫网站名称易与英语学习混淆——已改名：官网导航与卡片统一为「Python爬虫学习」与「英语学习」
  • 29英语网站页面仍显示 Python 爬虫内容——已彻底修复：模板继承路径改为独立的英语模板（en/base.html），清除全部爬虫残留，英语站所有页面恢复正常
  • 30控制台官网状态显示未知——已修复 GitHub Token 注入：Token 改为本地原生桥接提供，控制台官网状态、维护、音乐等功能恢复正常
  • 31控制台连不上 pythonanywhere API（网络限制）——已改用网站自身代理通道：状态/CPU/重启走学习网站代理接口，不再依赖手机直连 pythonanywhere；英语站同步支持
  • 32控制台无法感知版本更新——已加入版本检测：顶部检测按钮 + 启动自动检测，发现新版本弹窗询问是否更新
  • 33控制台版本检测"假更新"——已修复：远程加载成功即视为已是最新，不再重复提示；仅本地回退时才提示更新
  • 34英语网站新用户无分级——已加入新手分级测试：注册后先做 10 道英语题判定水平，基础好（答对7+）直接跳过基础篇从第 5 关开始，中等从第 3 关，基础弱从第 1 关
