FAQ

常见问题

生成的 App 是什么形态？

「页面工程 + 内置运行时」的轻量安卓应用：界面与逻辑用 HTML/CSS/JS 编写，运行在手机自带内核里，最终打成标准 APK。好处是编译与签名都能在手机上完成；局限是不涉及需要深度调用系统硬件的能力。

需要自己有 AI 的 API Key 吗？

不需要，装好即可使用内置模型通道。想让效果更贴合自己的习惯，可在「设置 → 模型通道」里选择服务商模板（DeepSeek、智谱、硅基流动、阿里通义、Kimi、火山方舟等 13 家），粘上自己的 Key 即可。Key 用系统密钥库加密保存，不落明文，也不会随工程包导出。

安装时提示「未知来源」怎么办？

安装包是自签名分发的，没有走应用商店。在系统设置里允许「爱创」安装应用一次即可，之后导出自己的 App 也用得到这个权限。

更新会让我重新下载整包吗？

不会。界面与逻辑的更新通过增量补丁下发，通常只有几十到一百多 KB，下载完点「立即重启生效」即可；只有涉及原生模块的改动才需要装整包。

项目数据存在哪里？会丢吗？

全部保存在手机本机（应用私有目录），不上传服务器。建议在关键节点手动创建快照，出问题可一键回退；也可以导出工程备份包自行留存。

支持 iOS 吗？

目前只提供安卓版。iOS 的打包链路需要开发者证书与 Mac 环境，无法在手机上完成，暂不在范围内。
