Overview

手机上的开发台，不依赖电脑

传统做法要装 IDE、配 SDK、连数据线。爱创把这些收进一部手机： 说清你要什么，剩下的环节由 AI 逐步完成，每一步都能看见它在想什么、改了什么。

Capabilities

它替你完成的六件事

不是生成一段代码片段，而是从一句需求走到一个可安装的成品。

自然语言开发

描述功能、页面与交互即可开工。AI 先做需求预审，信息不足时用选项卡片询问，而不是自行猜测。

流式思考可见

状态标签与思考原话成对实时下发：想到一步、界面刷新一步，过程的判断依据都摆在明面上。

实时预览

免打包直接看到成品界面，支持分屏边改边看、80% 至 125% 缩放，素材图片自动内联。

改动先看 Diff

混合模式下所有代码变更先给差异对比，绿加红删、按文件勾选，确认后才写入工程。

一键打包签名

在手机内完成换包名、换图标、重签名与完整性校验，直接导出可安装的 APK，附 MD5 与 SHA-256。

热增量更新

只下载与服务器不同的那几个文件，重启界面即生效；移动网络下默认只提示、不自动下载。

FAQ

常见问题

生成的 App 是什么形态？

爱创产出的是「页面工程 + 内置运行时」的轻量安卓应用：界面与业务逻辑用 HTML/CSS/JS 编写，运行在手机自带内核中，最终打成标准 APK。好处是全部编译与签名都能在手机上完成；局限是不涉及需要深度调用系统硬件的能力。

需要自己有 AI 的 API Key 吗？

不需要，装好即可使用内置模型通道。想让效果更贴合自己的习惯，可在「设置 → 模型通道」里选择服务商模板（DeepSeek、智谱、硅基流动、阿里通义、Kimi、火山方舟等 13 家），粘上自己的 Key 即可，地址与模型名会自动填好。Key 用系统密钥库加密保存在本机，不落明文，也不会随工程包导出。

安装时提示「未知来源」怎么办？

安装包是自签名分发的，没有走应用商店。在系统设置里允许「爱创」安装应用一次即可，之后导出自己的 App 也用得到这个权限。

更新会让我重新下载整包吗？

不会。界面与逻辑的更新通过增量补丁下发，通常只有几十到一百多 KB，下载完点「立即重启生效」即可；只有涉及原生模块的改动才会需要装一次整包。

项目数据存在哪里？会丢吗？

全部保存在手机本机（应用私有目录），不上传服务器。建议在关键节点手动创建快照，出问题可一键回退；也可以导出工程备份包自行留存。

支持 iOS 吗？

目前只提供安卓版。iOS 的打包链路需要开发者证书与 Mac 环境，无法在手机上完成，暂不在范围内。
