Features

它替你做的六件事

不是生成一段代码片段，而是从一句需求走到一个能安装的成品。

自然语言开发

描述功能、页面与交互即可开工。AI 会先做需求预审，信息不足时用选项卡片问你，而不是瞎猜。

流式思考可见

状态标签与思考原话成对流式下发：想到一步、界面刷新一步，你能看见它在分析什么、打算怎么做。

实时预览

不用打包就能看到成品界面，支持分屏边改边看、80% 到 125% 缩放，图片素材自动内联。

改动先看 Diff

混合模式下所有代码变更先给差异对比，绿加红删、按文件勾选，你点头了才写进工程。

一键打包签名

在手机内完成换包名、换图标、重签名与完整性校验，直接导出可安装的 APK，并附带 MD5 与 SHA256。

热增量更新

只下载与服务器不同的那几个文件，重启界面即生效，不重下整包；移动网络下默认只提示不下载。

FAQ

常见问题

生成的 App 是什么形态？和真正的安卓原生有什么区别？

爱创产出的是「页面工程 + 内置运行时」的轻量安卓应用：界面与业务逻辑用 HTML/CSS/JS 编写，运行在手机自带的内核里，最终打成标准 APK。好处是能在手机端完成全部编译与签名，不用电脑；局限是不涉及需要深度调用系统硬件的能力。

需要自己有 AI 的 API Key 吗？

不需要。软件内置了可用的模型通道，装好就能用。如果想让效果更好，可以在「设置 → 模型通道」里选择服务商模板（DeepSeek、智谱、硅基流动、阿里通义、Kimi、火山方舟等 13 个），粘上自己的 Key 即可，地址和模型名会自动填好。Key 用系统密钥库加密保存在本机，不会明文落盘，也不会随工程包导出。

为什么安装时提示「未知来源」？

因为安装包是自签名分发的，没有走应用商店。在系统设置里允许「爱创」安装应用一次即可，之后打包自己的 App 也用得到这个权限。

更新会不会每次都让我重下安装包？

不会。界面与逻辑的更新通过热增量补丁下发，通常只有几十到一百多 KB，下载完点「立即重启生效」就行；只有涉及原生模块的改动才会让你装一次整包。

我做的项目数据存在哪里？会不会丢？

全部存在手机本机（应用私有目录），不上传服务器。建议在关键节点手动创建快照，出问题可以一键回退；也可以导出工程备份包自己留存。

支持 iOS 吗？

目前只提供安卓版。iOS 的应用打包链路需要开发者证书与 Mac 环境，无法在手机上完成，暂不在范围内。
