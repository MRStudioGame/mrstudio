帮助与教程

1. Windows 绿色版（zip）怎么玩

① 点击「Windows下载」下载 zip 文件。
② 下载完成后，右键点击文件 → 选择「全部解压缩」。
③ 打开解压出的文件夹 → 双击 renpy.exe（老蒋/上位）或 鹦鹉物语.exe 即可游玩。
④ 首次启动可能需要几秒钟，请耐心等待。

2. Windows 安装版（exe）怎么装

① 下载 exe 后双击运行。
② 若弹出「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」（未签名应用属正常提示）。
③ 点「安装」，选择位置（默认即可），完成后自动启动游戏。

3. 安卓版（APK）怎么装

① 点击「下载安卓版」下载 apk 文件。
② 打开文件，若提示「未知来源」→ 点「设置」允许 → 返回安装。
③ 安装完成后，桌面出现游戏图标，点击即玩。

4. 下载慢或失败怎么办

① 网站下载已走国内加速通道，仍慢可尝试切换网络（WiFi/手机流量）或稍后再试。
② 也可以电脑上下载后，通过微信文件传输助手或数据线传到手机。

5. 游戏闪退 / 黑屏

① 更新显卡驱动。
② 若杀毒软件误报，请将游戏加入白名单或暂时关闭后重试。
③ Windows 7 系统建议升级到 Windows 10/11。

6. 存档在哪里

① Windows：%APPDATA%\RenPy\（对应游戏目录）。
② 安卓：手机内部存储 → Android/data/（对应包名）。
