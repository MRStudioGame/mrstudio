帮助与教程

遇到问题？这里都有答案

1. Windows 绿色版（zip）怎么玩

下载 zip → 右键「全部解压缩」→ 双击 renpy.exe（老蒋/上位）或 鹦鹉物语.exe。

2. Windows 安装版（exe）怎么装

双击 exe → 若提示「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」→ 点「安装」。

3. 安卓版（APK）怎么装

下载 apk → 打开 → 提示「未知来源」时点「设置」允许 → 安装 → 桌面出现图标即玩。

4. 下载慢或失败

切换网络（WiFi/流量）或稍后再试；也可电脑下载后通过微信/数据线传到手机。

5. 闪退 / 黑屏

更新显卡驱动；杀毒误报请加白名单；Windows 7 建议升级系统。

6. 存档位置

Windows：%APPDATA%\RenPy\；安卓：手机存储 → Android/data/。
